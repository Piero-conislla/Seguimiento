# ARQUIE — NeuroVisual & Funnel

## 1. Propósito
Esta Skill define el sistema de comunicación visual y persuasiva de ARQUIE — Arquitectura Empresarial Latam.

Debe utilizarse para crear imágenes, carruseles, infografías, anuncios B2B, piezas comerciales, piezas educativas, prompts para generación de imágenes y campañas sobre IA, automatización, procesos, datos, arquitectura empresarial y transformación digital.

Principio central:
ATENCIÓN → COMPRENSIÓN → CONFIANZA → VALOR → ACCIÓN.

No crear piezas aisladas sin considerar el objetivo dentro del funnel.

## 2. Posicionamiento ARQUIE
ARQUIE ayuda a empresas a mejorar sus procesos y convertirlos en sistemas digitales, automatizados e inteligentes.

La tecnología es un medio, no el producto final.

Evitar posicionar a ARQUIE como una simple empresa de software, agencia de diseño o empresa que vende herramientas de IA.

Transmitir:
EMPRESA + PROCESOS + TECNOLOGÍA + DATOS + RESULTADOS.

Idea central:
"No empezamos por la tecnología. Empezamos por entender el negocio."

## 4. Principios cognitivos
Aplicar psicología cognitiva y diseño de información de forma responsable.

Priorizar:
- atención selectiva
- jerarquía visual
- chunking
- fluidez cognitiva
- progresión
- concreción
- reducción de carga cognitiva
- memoria mediante estructuras repetibles

Una pieza debe comunicar principalmente UNA idea.

## 5. Neuroventas responsable
No utilizar pseudociencia ni afirmar que colores o estímulos obligan al cerebro a comprar.

Sí utilizar conceptos de:
- atención
- percepción
- carga cognitiva
- reconocimiento
- memoria
- emoción
- confianza
- reducción de incertidumbre
- facilidad de decisión

## 6. Funnel
Usar:
TOFU → MOFU → FOMO → BOFU

Nota: FOMO no es una etapa clásica independiente; es un disparador de decisión que puede incorporarse principalmente en MOFU y BOFU.

### TOFU — Atención
Objetivo: detener el scroll y despertar curiosidad.

Usar preguntas provocadoras, afirmaciones contraintuitivas, errores comunes, mitos y situaciones reconocibles.

Ejemplos:
- "Tu empresa no necesita más IA."
- "Digitalizar un mal proceso solo crea un mal proceso digital."
- "El Excel no es el problema."

Estructura:
GANCHO → CURIOSIDAD → IDEA CENTRAL

CTA suave:
"Descubre por qué", "Conoce el problema", "Lee el artículo", "Guarda este contenido".

### MOFU — Educación y autoridad
Objetivo:
"Esto me pasa."
"Ahora entiendo por qué."
"ARQUIE entiende este problema."

Formatos:
- frameworks
- rutas
- checklists
- infografías
- señales
- errores frecuentes
- comparaciones
- metodologías
- explicaciones
- casos conceptuales

Estructura:
PROBLEMA → EXPLICACIÓN → FRAMEWORK → INSIGHT → CTA SUAVE

Ejemplo de ruta:
01 DIAGNOSTICA
02 ORDENA
03 DIGITALIZA
04 AUTOMATIZA
05 INCORPORA IA
06 MIDE
07 OPTIMIZA

### FOMO — Costo de no actuar
Objetivo: hacer visible el costo de mantener el problema.

El FOMO debe ser empresarial y racional, nunca miedo artificial.

Cuatro pérdidas:
- tiempo
- dinero
- riesgo/control
- oportunidades

Ejemplos:
"¿Cuánto te cuesta seguir haciendo esto manualmente?"
"El costo no siempre está en el software. A veces está en seguir trabajando igual."

Estructura:
GANCHO DE PÉRDIDA → COSTO → CONTRASTE → CONSECUENCIA → CTA

Nunca inventar cifras ni utilizar escasez falsa.

### BOFU — Conversión
Objetivo: convertir interés en acción.

Responder:
- qué hacemos
- cómo lo hacemos
- qué recibe el cliente
- qué beneficio obtiene
- por qué ARQUIE
- cuál es el siguiente paso

Estructura:
PROBLEMA → SOLUCIÓN ARQUIE → ENTREGABLE → BENEFICIOS → PRUEBA → DIFERENCIADOR → CTA

Ejemplo:
DIAGNÓSTICO → DISEÑO → AUTOMATIZACIÓN → INTEGRACIÓN → IA → INDICADORES

CTA:
"Solicita un diagnóstico", "Agenda una reunión", "Evalúa tu proceso", "Conversemos sobre tu proyecto".

Usar un solo CTA principal.

## 7. Modelo visual
Toda pieza debe intentar seguir:
1. DETENER
2. HACER ENTENDER
3. HACER CREÍBLE
4. HACER DESEABLE
5. HACER ACTUAR

Preguntas de control:
¿Qué debe ver primero?
¿Qué debe entender después?
¿Qué debe recordar?
¿Qué debe hacer?

## 8. Prompt maestro para imágenes
Usar como base:

"Actúa como Director de Arte Senior especializado en comunicación B2B, psicología cognitiva aplicada al diseño, branding tecnológico y visualización de procesos empresariales.

Diseña una pieza visual para ARQUIE — Arquitectura Empresarial Latam.

La pieza debe transmitir una empresa B2B tecnológica, estratégica, confiable, sofisticada, moderna y orientada a resultados.

Aplicar jerarquía visual, contraste, agrupación de información, chunking, fluidez cognitiva, progresión visual, reconocimiento rápido y reducción de carga cognitiva.

La pieza debe seguir:
ATENCIÓN → COMPRENSIÓN → CONFIANZA → VALOR → ACCIÓN.

Usar azul #0C489C, celeste #009CD8, gris #848484 y blanco. El lila puede utilizarse como color de apoyo.

Usar tipografía sans serif moderna, limpia y altamente legible.

Priorizar diagramas, procesos, datos, dashboards, sistemas conectados, automatización, IA e interfaces empresariales.

Evitar neón, cyberpunk, exceso de brillo, colores estridentes, estética de videojuego y stock fotográfico genérico.

La composición debe estar optimizada para visualización móvil y mantener suficiente espacio negativo.

Una imagen debe comunicar principalmente UNA idea.

No inventar cifras, clientes, certificaciones, testimonios o resultados."

Después añadir las instrucciones específicas de TOFU, MOFU, FOMO o BOFU.

## 9. Prompt comercial
Para BOFU:
"Prioriza RESULTADO sobre TECNOLOGÍA.

Mostrar:
PROBLEMA → TRANSFORMACIÓN → SOLUCIÓN → BENEFICIO → CTA.

La persona debe comprender rápidamente:
1. Qué problema resolvemos.
2. Qué cambia después.
3. Qué debe hacer ahora.

No convertir la pieza en una lista de tecnologías."

## 10. Prompt educativo
Para TOFU/MOFU:
"Prioriza EDUCACIÓN y AUTORIDAD.

Mostrar una idea empresarial compleja mediante una estructura visual sencilla.

Usar preguntas, rutas, pasos, comparaciones, antes/después, frameworks o checklists.

No parecer publicidad agresiva.

La persona debe obtener valor incluso si no compra ningún servicio."

## 11. Prompt FOMO
"Prioriza el COSTO DE NO ACTUAR.

Mostrar cómo un proceso ineficiente puede consumir:
TIEMPO
DINERO
CONTROL
INFORMACIÓN
OPORTUNIDADES

No utilizar miedo artificial, escasez falsa ni cifras inventadas.

El mensaje debe ser incómodo pero profesional."

## 12. Prompt BOFU
"Prioriza CONFIANZA y CONVERSIÓN.

Mostrar:
PROBLEMA → SOLUCIÓN ARQUIE → ENTREGABLE → BENEFICIO → PRUEBA → CTA.

La solución debe ser concreta.

El CTA debe ser único, visible y de alta intención.

No saturar de información tecnológica."

## 13. Texto en imágenes
Titular ideal: 3–10 palabras.
Subtítulo: una frase breve.
Bloques: máximo una línea o concepto por bloque.
CTA: 2–5 palabras cuando sea posible.

Si requiere mucha explicación, convertir en carrusel.

## 14. Carruseles
Narrativa recomendada:
Slide 1: GANCHO
Slide 2: PROBLEMA
Slide 3: POR QUÉ OCURRE
Slides 4–6: SOLUCIÓN / FRAMEWORK
Slide 7: INSIGHT
Slide 8: CTA

Mantener consistencia visual entre slides.

> Ver también `arquie-crear-carrusel` para la plantilla de 8 láminas orientada a conversión (sección 6.3 del Brand Prompt Book), que es la versión oficial recomendada para campañas.

## 15. Datos y resultados
Nunca inventar:
- porcentajes
- ahorros
- horas recuperadas
- ROI
- clientes
- testimonios
- certificaciones
- casos de éxito

Si falta un dato:
- usar lenguaje conceptual;
- pedir el dato;
- o usar un placeholder como "[X horas recuperadas al mes]".

## 16. Diferenciador
Cuando corresponda, usar:
"No empezamos por la tecnología. Empezamos por entender el negocio."
"La tecnología es el medio. El resultado es el objetivo."
"Primero ordena el proceso. Después automatiza."
"Digitalizar no es mejorar."
"Automatizar un mal proceso no lo convierte en un buen proceso."
"IA donde realmente agrega valor."

No usar todos a la vez.

## 17. Control de calidad
Antes de entregar un prompt:
[ ] objetivo del funnel claro
[ ] una sola idea principal
[ ] titular rápido de entender
[ ] jerarquía visual
[ ] problema o beneficio evidente
[ ] suficiente espacio negativo
[ ] paleta ARQUIE
[ ] sin estética genérica de IA
[ ] sin pseudoneurociencia
[ ] sin datos inventados
[ ] CTA adecuado al funnel
[ ] funciona en móvil
[ ] tecnología como medio, no como fin

## 18. Comportamiento de la Skill
Cuando el usuario diga "Quiero una imagen sobre X":
1. identificar objetivo;
2. audiencia;
3. funnel;
4. problema;
5. resultado;
6. CTA.

Si el funnel no está especificado y no puede inferirse, preguntar:
"¿La quieres para TOFU, MOFU, FOMO o BOFU?"

Si el contexto es suficiente, no preguntar innecesariamente.

Cuando el usuario pida un prompt:
- entregar el prompt listo para generación;
- no explicar teoría innecesariamente;
- mantener el ADN ARQUIE;
- adaptar la estructura al funnel.

Cuando pida una imagen directamente:
- aplicar este sistema como guía;
- mantener consistencia de marca;
- priorizar claridad sobre decoración.

## 19. Principio final
ARQUIE no debe comunicar:
"Tenemos muchas tecnologías."

ARQUIE debe comunicar:
"Entendemos tu negocio, identificamos dónde está el problema y utilizamos la tecnología adecuada para transformarlo."

La comunicación visual debe convertir:
PROBLEMA → COMPRENSIÓN → URGENCIA RACIONAL → CONFIANZA → ACCIÓN.

Este es el principio central de ARQUIE NeuroVisual & Funnel.
